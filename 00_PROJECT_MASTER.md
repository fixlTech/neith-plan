# Neith project master

Status: Draft planning baseline · 2026-09-29

## Purpose
Neith is a proposed unified creative editing and mixing platform for individual creators, teams, agencies, and enterprise production. This repository is the planning source of truth. It does not claim that a feature is implemented or approved.

## How to use this repository
- Start here, then read product vision, PRD, and module inventory in numeric order.
- `Proposed` means a candidate requiring product and technical review. `Approved` requires an entry in `15_ARCHITECTURE_DECISIONS.md`. `Existing` requires repository or deployed-system evidence.
- Record unresolved choices in `91_OPEN_QUESTIONS.md`; update the relevant canonical file and change log when resolved.
- Do not infer implementation status from a planning document. Link evidence in `90_CURRENT_STATUS.md`.
