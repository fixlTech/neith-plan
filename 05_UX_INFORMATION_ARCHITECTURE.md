# UX information architecture

Status: Proposed structure

## Navigation model
Organization → Space → Hub → App → Project → Editor. A Hub groups workflows; an App presents specialized tools over shared project data. Confirm names with users before freezing routes.

## Candidate hubs
Create, Media, Content, Brand, Review, Automate, Insights, Manage. The same project may appear through more than one hub without duplication.

## Editor modes
Quick, Studio, Focus, Review, Preview, Automation are candidates. Define each mode's available commands, panel visibility, selection behavior, unsaved-state transitions, and entitlement rules before implementation.

## Required UX specs
Desktop and mobile navigation maps; empty/loading/error states; keyboard and touch interactions; onboarding; accessibility; panel registry; deep links; persistent user layout; role-sensitive affordances.

## Usability gate
Prototype the primary creation-to-export flow and review it with each priority persona before committing the navigation model.
